# Actape v1.1.0 · 统一触发键与简化操作录入

本次版本升级了 Actape 的核心交互。macOS 与 Windows 均支持用**鼠标侧键、键盘单键或组合快捷键**触发同一个可编辑宏，不再局限于鼠标侧键。

## 新增与改进

- **统一触发键**：直接录入鼠标侧键、键盘单键或组合键，并自动识别；每个宏独立保存触发配置。
- **两种触发模式**：单击启动（再次按下停止），或按住后循环执行、松开停止；macOS 也已支持按住模式。
- **步骤入口简化**：「添加步骤」仅显示「录入操作 / 输入文字 / 等待」三个选项，鼠标点击、拖动、滚动及键盘组合可以直接录入。
- **保留原始坐标**：编辑已有步骤时可替换鼠标点击或键盘按键，不清除已录制坐标、延迟及顺序。
- **绑定冲突处理**：重复分配同一触发键时提示确认；普通字母单键提示可能影响打字。
- **稳定性与兼容性**：隔离功能测试版与正式版宏数据；Windows 按住触发状态采用线程安全的跨线程判断；旧版宏和鼠标侧键绑定仍兼容。

## 使用

创建宏后，可点击「开始录制」记录整套操作，也可以用「添加步骤 → 录入操作」只记录一个动作。随后点击「设置触发键」，直接按目标鼠标侧键、键盘单键或组合键，再选择「单击」或「按住循环」。

F6/F7 继续用于录制与测试执行，不能直接设置为普通宏触发键。macOS 首次启动需授予输入控制权限。
