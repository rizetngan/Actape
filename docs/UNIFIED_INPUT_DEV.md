# Actape 统一触发与简化步骤（功能测试版）

分支：`feature/preserve-coordinates-key-input`。不会覆盖已发布的 v1.0.1。

## 操作方式

**添加步骤：** 点击「添加步骤」，只显示「录入操作」「输入文字」「等待」。

- 录入操作：在目标窗口完成一次鼠标点击、拖动、滚动或键盘组合，自动生成步骤。按 Esc 取消；Windows 也支持点击「取消录入」。
- 输入文字：插入可编辑的文字步骤。
- 等待：插入独立的延迟步骤。
- 已存在的鼠标按下/松开、键盘按下/松开等底层步骤保留，仍能通过高级步骤编辑器访问。

**设置触发键：** 点击「设置触发键」，直接按鼠标侧键、键盘单键或组合键；Esc 取消。每个宏只绑定一个触发输入。

- 单击：按一次启动，第二次按下停止。
- 按住循环：按住自动循环宏，松开主键、鼠标侧键或必要的修饰键立即停止。
- 普通字母单键：有全局打字冲突确认。
- 触发键已分配其他宏：提示确认后才能转移。
- F6/F7 是全局录制/执行快捷键，不能直接用作宏触发键。
- 宏回放产生的合成事件不会再次触发绑定宏。

## 兼容与限制

- Windows 旧版的 SideButton/Trigger 字段保留，新增键码和修饰键字段，原有绑定仍可加载。
- macOS 旧版 `triggerButton` 字段保留，新增可选的键盘触发、修饰键、按住模式字段；旧宏可直接解码。
- 坐标/延迟/顺序不会因改换鼠标点击或键盘快捷键而删除。
- 标准侧键 4/5 直接支持；若厂商驱动将侧键映射成键盘信号，则按映射后的键绑定。
- 单步「录入操作」主要识别一次完整动作；连续双击和连续多次滚轮的自动合并尚需下一轮实机完善，可暂用完整录制流程。
- macOS 目前为本机调试签名和 CI 构建验证；未做正式公证。

## 本轮验收

- Windows 本地 .NET 8 兼容构建、GitHub .NET 10 构建通过。
- Windows 原生 UI：「设置触发键」可进入/退出；添加步骤只有三个入口。
- Windows 数据模型：旧版侧键 JSON、键盘快捷键、按住模式、往返存储测试通过。
- macOS 本机 Xcode 编译、GitHub CI 构建通过。
- 真实物理键盘的全局捕获、组合键冲突、长按与释放尚需实体实测；测试版不作为正式版发布。

## 后续验收重点

真实鼠标侧键和键盘（F8、Ctrl+Shift+S / macOS ⌘+Shift+S）分别测试：
1. 绑定、保存、退出重启后是否保留；
2. 单击启动/再次按下停止；
3. 按住持续循环与松开停止；
4. 录入状态下按键不触发旧宏，Esc 正常取消；
5. 同一触发键转移到另一个宏需确认；
6. 旧宏的侧键和坐标不丢失。
