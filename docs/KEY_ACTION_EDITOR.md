# Actape — 保留坐标，替换执行动作

适用：`feature/preserve-coordinates-key-input` 开发测试版；不属于已发布的 v1.0.1。

## 操作

1. 在录制好的宏里选中一个「鼠标点击」步骤。
2. 将「执行动作」从「鼠标点击」切换成「键盘按键」。
3. 点击「录入按键」，按下单键或组合键（如 Ctrl+C、Shift+S 或 macOS ⌘V），松开主键后保存；按 Esc 或再次点击录入按钮可取消。
4. 原步骤 X/Y、延迟、步骤 ID 和原鼠标按键/点击次数全部保留，键盘动作本身不会先点击原坐标。
5. 需要恢复时切回「鼠标点击」，原有鼠标操作配置和坐标即可直接使用。

## 执行边界

- 一步键盘动作执行完整的一次按下和松开；异常结束或停止时释放模拟按键。
- Windows 使用本机 VK、Ctrl / Alt / Shift / Win 修饰键；macOS 使用原生虚拟键码和 Command / Option / Control / Shift / Fn 修饰键。
- 系统原始键盘按下/松开步骤、原有文字输入/序列等高级步骤不受替换入口影响。
- 兼容历史宏的 JSON 数据；新增字段具有默认值。

## 已验证

- Windows：本机编译通过、原生 UI 切换测试通过；以 (680, 340) 与 150 ms 测试，切换前后 JSON 值不变。
- Windows：启动/取消录入按钮状态及历史按键保留检查通过；临时测试宏已清理。
- macOS：Xcode Debug 构建通过，Swift 模型 JSON 编码/解码及坐标、延迟、步骤 ID 保留测试通过。

## 实机待验证

- macOS / Windows：真实键盘输入捕获 Ctrl+C、Shift+S、Cmd+V 等组合键。
- 目标应用中的快捷键回放是否按预期执行；录入 Esc 能否退出；F6/F7 录入阶段是否与全局快捷键冲突。
- 原有数据多次退出重启后的保存一致性。

功能分支完成实机验收后，再考虑合并到 `main` 和发布新版本。
